# Честный Отзыв

Веб-приложение для размещения отзывов о товарах и услугах.

## Инструкция по установке

Инструкция по установке и запуску

1. Клонируйте репозиторий
   git clone <ссылка-на-репозиторий>
   cd otzivBD

2. Запустите Docker Desktop

3. Запустите контейнеры
   docker-compose up -d

4. Дождитесь запуска (10-30 секунд)

5. Откройте браузер и перейдите по адресу
   http://localhost:3000/

Остановка приложения:
   docker-compose down

Перезапуск:
   docker-compose up -d

## Как получить права администратора
1. Зарегистрируйте пользователя
2. Зайти в adminer (http://localhost:8080/) (Логин: root, Пароль: root)
3. Перейти в БД otzivBD
4. Перейти в таблицу users
5. Нажать кнопку "выбрать"
6. Нажать кнопку "редактировать"
7. Поменять роль на admin

После этого у пользователя появится панель администратора, в которой можно менять категории, товары, теги, рассматривать жалобы и управлять пользователями.
